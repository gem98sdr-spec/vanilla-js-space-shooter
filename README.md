🚀 Neon Strike: Cyberpunk Space Shooter

A fast-paced, synthwave-inspired HTML5 canvas arcade game built entirely in a single file.

Defend your base against relentless enemy waves in a retro-futuristic grid.

🎮 About The Game

Neon Strike is a modern love letter to classic arcade shooters (like Galaga and Space Invaders) but infused with modern "Game Feel" (Juice). It features a custom procedural Web Audio synthesizer, screen-shake, particle physics, and a 3D parallax synthwave background—all running without a single external image or sound asset.

✨ Features

Zero Assets Needed: Everything is drawn procedurally via Canvas API.

Built-in Synthesizer: All sound effects (lasers, explosions, UI) are generated live using the Web Audio API.

Dynamic Difficulty: 4 modes ranging from Easy to the chaotic "Iran Mode" (Bullet Hell).

Base Defense Mechanic: Enemies passing the bottom of the screen deal damage to your health!

Combo System: Chain kills to multiply your score and accelerate the background music.

Mobile Ready: Fully responsive design with touch-drag support and smart finger-offset.

Controls

Desktop: Use your Mouse to move the ship. The ship fires automatically. Press ESC or P to Pause.

Mobile/Tablet: Drag anywhere on the screen to move the ship.

🛠️ Power-ups

Destroying the heavily armored red Tanks (or sometimes regular enemies) drops capsules:

🟢 [ + ] Health: Restores 40 HP.

🔵 [ O ] Shield: Temporary invulnerability.

🟡 [ R ] Rapid Fire: Dramatically increases attack speed.

🟣 [ S ] Spread: Fires a wide, 3-way laser beam.

💻 Installation & Usage

Because the game is 100% contained in a single file, there is no build process or package manager required!


Open index.html in any modern web browser.

Enjoy!
